# BackendTasks

A curated collection of **backend-focused tasks and practice projects** that I use while teaching backend development at my academy.

This repository is intentionally **hands-on**: each folder is designed to help students practice core concepts through small, focused exercises and mini-projects.

---

## What you’ll find here

- Practical backend exercises and assignments
- Step-by-step learning through real code
- Examples that can be used in lessons, homework, or self-study

The codebase includes backend work as well as basic UI assets (HTML/CSS/SCSS/JS) used for demos or simple frontends.

---

## Tech stack (current)

- **C#** (primary)
- **HTML / CSS / SCSS**
- **JavaScript**

> Language distribution (approx.): C# ~39.7%, CSS ~38.4%, HTML ~15%, SCSS ~3.7%, JavaScript ~3.2%

---

## How to use this repo

1. **Browse by folder** and pick a task.
2. Read any notes/instructions inside the task directory (if present).
3. Implement the solution (or review the reference solution, if available).
4. Extend it with improvements:
   - validation
   - logging
   - error handling
   - clean architecture / layering
   - unit tests

---

## Recommended workflow for students

- Fork the repository
- Create a new branch per task:
  - `feature/task-<name>` or `practice/<topic>`
- Commit small, meaningful changes
- Open a Pull Request when you want feedback
