## 🎯 Purpose

This repository is maintained for **Code Academy** learners who want structured, practical work alongside their lessons.
Each folder contains a focused task or mini‑project aimed at strengthening core backend development skills through implementation.

---

## 📦 What you’ll find here

- ✅ Backend exercises and assignments (hands-on)
- 🧩 Small, focused practice projects
- 🪜 Step-by-step learning through real code
- 🧪 Opportunities to extend tasks with testing and best practices

> Note: While the primary focus is backend development, the repository may also include simple UI assets (HTML/CSS/SCSS/JS) used for demos and lightweight frontends.

---

## 🧰 Tech stack (current)

- **C#** (primary)
- **HTML / CSS / SCSS**
- **JavaScript**

---

## 🚀 How to use this repository

1. 📁 **Browse by folder** and pick a task.
2. 📝 Read any `README` / notes inside the selected task directory (if provided).
3. 💻 Implement your solution.
4. 🧠 Improve it further by adding:
   - input validation
   - logging
   - error handling
   - clean architecture / layering
   - unit tests

---

## 🌿 Recommended workflow for students

- Fork this repository
- Create a new branch per task:
  - `feature/task-<name>`
  - `practice/<topic>`
- Commit small, meaningful changes
- Open a Pull Request when you want feedback

---

## 🤝 Contributing
